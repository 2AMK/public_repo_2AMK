# Expressões regulares em Python

A expressão `\b` tanto no início ou final da expressão regular irá procurar por um espaço vazio antes (se colocar no começo) e depois (se colocar no final) da palavra procurada. Veja no exemplo abaixo:
```python
# 3- Crie um REGEX em Python para extrair as palavras seguidas por exclamação.
match = re.findall(r"\b\w+!", musica)

print(match)
```
- No exemplo acima, `\b` no começo indica que a expressão regular deve procurar as palavras antes da pontuação `!` como no resultado: `['selvagem!', 'Selvagem!', 'Selvagem!', 'jovens!', 'jovens!']`
- Não pode colocar `\b` na última 

No outro exemplo:
```python
# 2- Crie um REGEX em Python para contar quantas vezes a palavra tempo aparece na música.
match = re.findall(r"\btempo\b", musica)
count = len(match)
print("A palavra 'tempo' aparece", count, "vezes no texto.")
```
