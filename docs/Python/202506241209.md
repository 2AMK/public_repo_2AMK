# Manipulação de arquivo

Pode-se usar o modo write no arquivo usando o parâmetro `"w"`. 
```python
# Abrindo arquivo para gravação
arq2 = open("arquivos/arquivo2.txt", "w") # w = write
```
- Se o arquivo não existir em primeiro lugar, ele será criado em primeiro lugar.

> [!caution] 
> Tenha cuidado com o modo de write do `open` pois esse comando **irá sobrescrever permanentemente** os conteúdos existentes no arquivo!
> 

É importante destacar que caso tenha usado o comando no modo `write`, você não poderá executar determinados comandos como `.read()` pois o arquivo estará marcado só para escrever, não para ler.

Para gravar um conteúdo no arquivo, pode-se usar o comando `.write( <conteúdo> )` no Python.
```python
# Gravando arquivo
arq2.write("Aprendendo a programar em Python.")
```

Para fechar uma sessão no arquivo, pode-se usar o método `.close()`. Assim, posteriormente você também poderá fazer outras operações sobre o arquivo como ler o arquivo ou acrescentar os conteúdos.
```python
print(arq2.read())
```
- Podemos ler o conteúdo usando a função `print()` e `.read()`

Também podemos acrescentar mais conteúdo a um arquivo usando o modo de `"a"` que é o modo append. É importante destacar que caso tenha efetuado o comando `.read()` antes (ou com alguns parâmetros numéricos como `.read(20)`), o conteúdo será acrescentado na posição onde o Python está lendo.
- Ou seja se o "cursor do texto" estiver no final, o Python irá acrescentar o texto exatamente no final.
- Há outro método de leitura como `.readlines()` que transforma o texto em uma lista e fazer leitura com separação do newline
```python
arq3.seek(0)
arq3.readlines()
```
- Resultado: 
	- `['Este arquivo foi gerado pelo Jupyter Notebook.\n',
	 - `'Podemos gerar quantas linhas quisermos e o Jupyter grava no arquivo final.\n']`

- Alternativamente, tem o loop `for` para iterar e ler o conteúdo do arquivo:
```python
# Podemos usar um loop for para ler o arquivo
for line in open('arquivos/arquivo3.txt'):
    print(line)
```


Veja o exemplo abaixo:
```python
# Acrescentando conteúdo
arq2 = open("arquivos/arquivo2.txt", "a") # a = append

# Escreve o conteúdo
arq2.write(" E a metodologia de ensino da Data Science Academy facilita o aprendizado.")

# Fecha o modo de append
arq2.close()
```

A partir do arquivo ".csv", aberto com mesmo método mencionado anteriormente, podemos também fazer a contagem das colunas e das linhas. 
- Para fazer a contagem de linhas:
```python
f = open('arquivos/salarios.csv', 'r')
data = f.read()
rows = data.split('\n')
full_data = []

for row in rows:
    split_row = row.split(",")
    full_data.append(split_row)

# Faz contagem das linhas
count = 0
for row in full_data:
    count += 1   # Equivalente a: count = count + 1

print(count)

```
- Para fazer a contagem das colunas:
```python
f = open('arquivos/salarios.csv', 'r')
data = f.read()
rows = data.split('\n')
full_data = []

for row in rows:
    split_row = row.split(",")
    full_data.append(split_row)
    first_row = full_data[0]

# Inicializa a contagem com zero
count = 0

for column in first_row:
    count = count + 1
    
# Outra solução possível
# for column in full_data[0]:
#     count = count + 1

print(count)
```

É interessante enfatizar que é possível gravar os arquivos pelo Jupyter Notebook usando os comandos mágicos `%%writefile` do próprio Jupyter Notebook, não do Python.
```
%%writefile arquivos/arquivo3.txt   
Este arquivo foi gerado pelo Jupyter Notebook.
Podemos gerar quantas linhas quisermos e o Jupyter grava no arquivo final.
```

Com a biblioteca `Pandas`, podemos fazer essas operações de abrir um dataset no formato de `.csv`com maior facilidade.
```python
import pandas as pd
arquivo = "arquivos/salarios.csv"

df = pd.read_csv(arquivo)
df.head()
```
- Para abrir um arquivo no formato de csv, podemos usar a função da própria Pandas `.read_csv( <arquivo>)`

E com isso, também podemos realizar várias operações envolvendo uma base de dados como `.value_counts()`:
```python
df['Position Title'].value_counts()
```
