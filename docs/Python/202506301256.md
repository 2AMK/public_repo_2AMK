É possível ver todos os métodos e atributos do python usando a função `dir()`

```python

dir(numpy)
```


# Módulo random

Com a função `random.choice`, nós podemos também escolher um elemento a partir de uma lista como segue no exemplo abaixo:
```python
random.choice(['Abacate', 'Banana', 'Laranja'])
```

A outra função `random.samples` da pacote `random` também permite extrair um número especificado de elementos a partir de uma amostra como segue no exemplo abaixo:
```python
random.sample(range(100), 10)
```
- Resultado:
```
[64, 43, 59, 44, 92, 21, 11, 62, 22, 29]
```
- Observe que o parâmetro de número 10 na função `sample`significa que irá extrair 10 elementos da lista.

## Módulo urllib
O módulo `urllib` permite extrair o conteúdo de um url para dentro do Python usando o módulo `urllib.request` e a função `urllib `
```python
# Importando o módulo request do pacote urllib, usado para trazer url's 
# para dentro do nosso ambiente Python
import urllib.request

# Variável resposta armazena o objeto de conexão à url passada como 
# parâmetro
resposta = urllib.request.urlopen('http://python.org')

# Objeto resposta
print(resposta)
```
- Resultado:
```
<http.client.HTTPResponse object at 0x7f8e46914a90>
```

Podemos também fazer uma leitura do conteúdo armazenado na variável atribuída:
```python
# Chamando o método read() do objeto resposta e armazenando o código 
# html na variável html
html = resposta.read()
```
