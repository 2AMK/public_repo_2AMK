# Manipulação de arquivo

Para abrir um arquivo para a leitura, pode-se usar o seguinte código:
```python
# Abrindo o arquivo para leitura
arq1 = open("arquivos/arquivo1.txt", "r") # r = read
```
- `"r"` marca que o arquivo só pode ser lido, mas não pode ser escrito.
- O comando `open()` irá abrir o arquivo e permite com que o usuário possa ver o conteúdo contido num arquivo, bem como escrevê-los.

Pode-se também ler o conteúdo existente no arquivo com seguinte comando `.read()`:
```python
# Lendo o arquivo
print(arq1.read())
```

Para ver quantos caracteres estão no arquivo em questão, pode-se usar o comando `.tell()`
```python
# Contar o número de caracteres
print(arq1.tell())
```

É importante destacar que o comando `.read()` no Python, caso você execute o comando novamente, o Python irá retornar nenhum conteúdo. Isso ocorre porque o "cursor do texto" foi até o fim e desse modo, não há nada que Python possa ler. 
- Nesse caso, é necessário você use o comando `.seek(0,0)` para voltar ao início do arquivo e assim usar o comando `.read()`
```python
# Retornar para o iníco do arquivo
print(arq1.seek(0,0))
```
- Também podemos especificar um número de caracteres no comando `.read()` para que o programa leia até uma determinada posição de caracteres.
```python
# Lendo os primeiros 23 caracteres
print(arq1.read(23))
```
