# Expressões Regulares em Python

Para ver mais informação sobre os regexes e as operações, pode-se usar esse link: https://docs.python.org/3.9/library/re.html

Podemos usar `re.findall()` para localizar os caracteres específicos ou uma cadeia de caracteres em uma string. Por exemplo, podemos verificar quantas vezes aparecem a arroba (@) em um texto.
```python
import re

texto = "Meu e-mail é exemplo@gmail.com e você pode me contatar em outro_email@yahoo.com."

# Expressão regular ver o caracter arroba aparece no texto
lista = re.findall("@", texto)

print(lista)
```
- Resultado: `['@', '@']`
- Nesse sentido, a sintaxe seria `re.findall( <caracteres>, <variável> )`

Se utilizar `len()` juntamente `re.findall()`, podemos também contar quantas vezes um determinado caractere aparece em uma string como no exemplo abaixo:
```python
# Expressão regular para contar quantas vezes o caracter arroba aparece no texto
resultado = len(re.findall("@", texto))

print("O caractere '@' apareceu", resultado, "vezes no texto.")
```
- Resultado: "O caractere '@' apareceu 2 vezes no texto."

Quando queremos colocar uma expressão regular no Python, sempre devemos colocar o `r"  "` (raw string) para tratar o string como literal, para evitar que o Python interprete errado essas expressões, especialmente o caractere de escape `\`. 

```python
# Expressão regular para extrair a palavra que aparece após a palavra "você" em um texto
resultado = re.findall(r'você (\w+)', texto)

print("A palavra após 'você' é:", resultado[0])
```
- Resultado: `A palavra após 'você' é: pode`
-  Observe que `'você (\w+)'` é um padrão de busca onde a regex irá procurar a palavra "você" com um espaço depois dessa palavra.  
- `\w` procura quaisquer caracteres (letras e números) que vem depois da palavra `você `. É como `[A-Za-z0-9_]`
- `(\w+)`, na parte de `+` procura capturar 1 ou mais caracteres.
- `resultado[0]` procura retornar a primeira correspondência que aparecer na lista do `re.findall()`

```python
# Expressão regular para extrair endereços de e-mail de uma string
emails = re.findall(r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b', texto)

print(emails)
```
- Resultado: `['exemplo@gmail.com', 'outro_email@yahoo.com']`
- Podemos usar essa expressão para extrair os endereços de e-mail usando três expressões regulares 
- Observe-se que cada `+` significa a concatenação de outras expressões regulares. 

Podemos achar os advérbios e suas posições usando `re.finditer()` como no exemplo abaixo:
```python
text = "Ela respondeu educadamente, caminhou silenciosamente pelo corredor e saiu rapidamente da sala."

# Extraindo os advérbios da frase
for m in re.finditer(r"\w+mente\b", text):
    print('%02d-%02d: %s' % (m.start(), m.end(), m.group(0)))
```
- Resultado:
```
14-26: educadamente
37-52: silenciosamente
74-85: rapidamente
```
- `m.start()` mostra a posição inicial do advérbio.
- `m.end()` mostra a posição final.
- `m.group(0)` retorna o advérbio completo.
