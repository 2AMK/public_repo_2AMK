Podemos juntar vários strings com a única variável como no exemplo abaixo:
```python
texto_exemplo = "É importante aprender Python.\n"
texto_exemplo = texto_exemplo + "Porque isso dá muitas oportunidades.\n"
texto_exemplo += "Também é bom para Data Science."

print(texto_exemplo)
```

Também é possível manipular os arquivos em TXT usando o módulo `os` que é um pacote de Python que permite interagir com o próprio sistema operacional. Para inserir isso no código, basta usar `import os`

Podemos criar um arquivo com o comando `open` como segue no comando abaixo:
```python
# Importando o módulo os
import os

# Criando um arquivo
arquivo_exemplo = open(os.path.join('arquivos/arquivo_exemplo.txt'), 'w') # Queremos ativar o modo de escrita

# Gravar os dados no arquivo
for palavra in texto_exemplo.split():
    arquivo_exemplo.write(palavra + " ")

# Fechando o arquivo
arquivo_exemplo.close()

# Lendo o arquivo
arquivo_exemplo = open('arquivos/arquivo_exemplo.txt', 'r') # No modo de leitura
conteudo = arquivo_exemplo.read()
arquivo_exemplo.close()
print(conteudo)
```
- Resultado: `É importante aprender Python. Porque isso dá muitas oportunidades. Também é bom para Data Science.`
- A expressão os.path.join, que está junto ao caminho do arquivo a ser criado, significa que queremos pegar o caminho do sistema operacional e juntá-lo com o caminho do arquivo.

É importante enfatizar que devemos sempre chamar o método `.close()` assim que terminar de manipular um arquivo. Se não fecharmos, podemos causar alguns problemas como corrupção dos arquivos e não podemos mexer esse arquivo em questão com os outros programas.
- Por essa razão, é interessante utilizar a expressão `with` que irá fechar sozinho por você assim que terminar de manipular esse tal arquivo.
