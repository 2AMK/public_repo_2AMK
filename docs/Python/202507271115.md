O método `maketrans` do `str` permite criar uma tabela de tradução em que substitui os caracteres por determinada string como no exemplo abaixo:
```python
str.maketrans({'t': 'c', 'l': 'b'})
```
- No exemplo acima, o caractere `t` será trocado por `c` e assim por diante.

```python
my_string = "tamperlot"
translation_table = str.maketrans({'t': 'c', 'l': 'b'})
translated_string = my_string.translate(translation_table)
```
- No outro exemplo, pode-se aplicar com o método `.translate()`

A função bulit-in `sum()` retorna a soma de todos os itens de um iterável (como lista, dicionário e tupla). Veja o exemplo abaixo:
```python
test = lambda x: x * 2
print(sum(map(test, [2, 3, 5, 8])))
```

O método `.join()` pode juntar os caracteres ou cadeia de caracteres em único string com separadores. Ou seja, é semelhante à concatenação de string como no exemplo abaixo:
```python
result_string = ''.join(characters)
```
- No exemplo acima, o método junta os elementos de uma lista de string em único string, concatenando os caracteres juntos usando o separador de `''` (string vazio).

O método `.strip()` remove os caracteres que estão à esquerda ou à direita. Ou seja é semelhante ao arrumar, removendo os espaços vazios à direita ou à esquerda. Veja no exemplo abaixo:
```python
original_string = "_example_string_"

clean_string = original_string.strip('_')
```
- Os caracteres `_` que estiverem à direita ou à esquerda vão ser removidas e resultaria em `'example_string'`.

Em list compehension com os condicionais, se você tiver apenas `if`, a expressão de `if` deve ser escrito por último como no exemplo:
```python
nomes = ["Ana", "Beatriz", "Lu", "Gabriel", "Sol"]
classificacao = []

for nome in nomes:
  if len(nome) > 3:
    resultado_nome = nome.upper()
    classificacao.append(resultado_nome)


# Como seria se fosse em list comprehension
classificacao = ["curto" if len(nome) <= 3 else "longo" for nome in nomes]
```
- Resultado: `['BEATRIZ', 'GABRIEL']`

Se for com `if else`, a expressão condicional deve ser escrito primeiro e depois colocar a expressão de `for`:
```python
nomes = ["Ana", "Beatriz", "Lu", "Gabriel", "Sol"]
classificacao = []
for nome in nomes:
  if len(nome) <= 3:
    resultado_nome = "curto"
    classificacao.append(resultado_nome)
  else:
    resultado_nome = "longo"
    classificacao.append(resultado_nome)

classificacao = ["curto" if len(nome) <= 3 else "longo" for nome in nomes]
```

Se tiver 2 ou mais `else`, tem que escrever `else Y if` como no exemplo abaixo:
```python
temperaturas = [27.5, 30.2, 21.8, 35.0, 19.6]
clima = ["frio" if temperatura <20 else "ameno" if temperatura < 30 else "quente" for temperatura in temperaturas]
```

A sintaxe deve ser assim desse jeito:
```python
X if condição1 else Y if condição2 else Z
```


Em list comprehension aninhado onde você precisa avaliar os elementos internos das listas de uma lista, você deve usar list comprehension duas vezes, primeiro para extrair cada lista. O segundo irá extrair o elemento individual da lista. Veja os exemplos abaixo:
```python
notas = [
    [7.5, 8.0, 6.5],  # aluno 1
    [9.0, 9.5, 8.5],  # aluno 2
    [5.0, 6.0, 4.5],  # aluno 3
]

avaliacoes = [["OK" if nota >= 7 else "ERRO" for nota in aluno] for aluno in notas]
```
- Resultado: `[['OK', 'OK', 'ERRO'], ['OK', 'OK', 'OK'], ['ERRO', 'ERRO', 'ERRO']]`
- No exemplo acima, veja que list comprehension externo extraiu as listas internas. E o outro list comprehension extraiu e avaliou cada elemento.


```python
nomes = ["amanda", "joão", "carla"]
aeiou = ["a", "e", "i", "o", "u"]

vogais_maiusculas = ["".join([letra.upper() if letra in aeiou else letra.lower() for letra in nome]) for nome in nomes]
```
- Resultado: `['AmAndA', 'jOãO', 'cArlA']`
- Nesse código, foram utilizados dois list comprehension, com intuito de pegar também as letras individuais dos nomes.
