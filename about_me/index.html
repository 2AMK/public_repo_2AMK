Sobre mim

Sou Analista Jr. de Remuneração, especializada em automação e otimização dos processos de Gestão de Pessoas com Python e SQL, além de certa experiência com Google App Script.

Meu objetivo é utilizar a engenharia de dados e automações internas para melhorar as rotinas e processos operacionais de uma área específica da Gestão de Pessoas para aumentar a eficiência e reduzir custos e tornar mais os processos mais fool-proofs e resilentes.

Possuo formação em Administração pela UNIFESP (2025), e conto com diversos projetos realizados até agora.

Minha filosofia

Busco as soluções mais eficientes, permanentes e que resolvam problemas reais, enquanto empodera os utilizadores das ferramentas internas, resgatando a autonomia deles.

Projeto e construo as soluções em que os usuários não precisam entrar e mexer no motor do código, mas sim apenas configurar de maneira mais simples, sem a necessidade de conhecimento técnico.

Com o background de Administração, também converso entre a área de negócio e a área técnica, sempre buscando entender as necessidades reais e dores do negócio e trazer as soluções que façam sentido para o contexto.

Principais projetos feitos até agora

Segue a lista resumida dos principais projetos profissionais que foram realizados até agora. Para mais detalhes, recomendo visitar a página meus projetos.

Automação de Relatório Gerencial

  • Um processo que antes demorava algumas horas para ser feito foi automatizado, reduzindo para alguns minutos
  • Script utiliza as bibliotecas Pandas e PyGUI para Python
  • Interface amigável para usuários não técnicos

Geração de PDF

  • Fiz melhorias importantes para automação já existente
  • Cortei as etapas intermediárias manuais e repetitiva
  • Transformei a rotina que demorava a "noite inteira" para umas dezenas de minutos
  • Usei Python com templates ajustáveis em HTML e multiprocessing para melhorar a performance

Enviador de PDF

  • Trouxe melhorias importantes para a rotina já existente de envio em massa de e-mail
  • Melhorei o código legado para ser mais resilente e mais documentável
  • Tornei o processo mais escalável, usando as chamadas de API a um SMTP, invés de provedor nativo

Consolidador de Apurações

  • Modernizei o código legado para gerar os logs auditáveis
  • Agora o código permite gerar uma planilha pronta com todas as apurações
  • Também tirei a necessidade de agendar manualmente os acionadores e fiz com que a automação execute com base no cronograma definido

Projeto de Chatbot AI

  • Liderei tecnicamente e atuei como dev solo do projeto de GEN AI do time não técnico
  • É um projeto altamente experimental e complexo que integra o chatbot com a plataforma de dados e aplicativo de mensagens
  • Faz o uso dos tools calling para tornar as respostas mais inteligentes sem depender do "Chain of Responsibility"

Motor de Processamento e Geração de Output

  • A rotina tinha vários problemas que eliminei:
    • O excessivo do tempo gasto no processo de busca manual repetitivo usando Excel (um problema extremamente comum em várias empresas!)
    • A necessidade de puxar várias planilhas diferentes para obter os dados necessários
    • A falta reutilização do modelo para uma rotina complexa e recorrente
  • Implementei um motor poderoso que combina diferentes fontes e gera uma saída personalizada baseado nos parâmetros ajustáveis
  • A automação permite a independência do usuário final de ajustar o modelo conforme necessário e reutilização do modelo para próximas rotinas
  • Espera-se que este projeto reduza 2 a 3 dias de trabalho de trabalho bruto e manual em poucos minutos e menos lesão nos pulsos das mãos dos usuários

Automação de Consolidação de Formulários

  • Projeto feito em colaboração com o outro time
  • Estou desenvolvendo um motor interno que atua como backend das planilhas de formulários e planilha central
  • A automação consolida os diferentes formulários de ingestão em única planilha central, com validação e tratamento dos dados.
  • Projetei para permitir a autonomia por parte dos utilizadores finais ao tornar mais fácil de configurar e ajustar.
