# Manipulação de arquivo
Ao usar a expressão `with` na hora de abrir e fazer algumas manipulações, você não precisará chamar o método `.close()` pois essa expressão irá executar `.close()` automaticamente.

Para abrir um arquivo com essa expressão:
```python
# Abrindo um arquivo
with open('arquivos/arquivo_exemplo.txt') as arquivo_exemplo:
    conteudo_exemplo = arquivo_exemplo.read()

print(conteudo_exemplo)
```
- Resultado: "É importante aprender Python. Porque isso dá muitas oportunidades. Também é bom para Data Science."

Para escrever um arquivo:
```python
# Escrevendo o arquivo
with open('arquivos/arquivo_exemplo.txt', 'a') as arquivo_exemplo:
    arquivo_exemplo.write("\nAproveite para estudar enquanto puder, pois cada migalha de conhecimento é um passo mais próximo para seu destino!")

# Lendo o arquivo
with open('arquivos/arquivo_exemplo.txt') as arquivo_exemplo:
    conteudo_exemplo = arquivo_exemplo.read()

print(conteudo_exemplo)

```
- Resultado: 
	- É importante aprender Python. Porque isso dá muitas oportunidades. Também é bom para Data Science.
	- Aproveite para estudar enquanto puder, pois cada migalha de conhecimento é um passo mais próximo para seu destino!

Quanto aos arquivos no formato `.csv`, podemos utilizar o módulo `csv` do Python. Veja como podemos abrir o arquivo no formato `.csv` e fazer algumas manipulações:
```python
# Importando o módulo csv
import csv

with open('arquivos/matriz_exemplo.csv','w') as arquivo_exemplo:
    # Criando objeto de gravação
    writer = csv.writer(arquivo_exemplo)

    # Gravando no arquivo
    writer.writerow(("Coluna1", "Coluna2", "Coluna3"))
    writer.writerows([(12,22,83), (45, 34, 54), (19, 31, 8)])
    writer.writerow((87,56, 21))
```
- Observe que `writer.writerows` só aceita único argumento, e portanto é necessário montar esses conjuntos em uma lista.

Para ler os arquivos em .csv:
```python
# Leitura de arquivos csv
with open('arquivos/matriz_exemplo.csv', 'r', encoding = 'utf8', newline = '\r\n') as arquivo_exemplo:

    # Criando o objeto de leitura
    leitor = csv.reader(arquivo_exemplo)

    # Usando loop para ver o conteúdo:
    for x in leitor:
        print(x)
```
- Resultado:
```
['Coluna1', 'Coluna2', 'Coluna3']
['12', '22', '83']
['45', '34', '54']
['19', '31', '8']
['87', '56', '21']
```
- É importante usar o parâmetro `newline = '\r\n'` para que não considere os newlines como linhas. Se não o fizer, você receberá resultado estranho como vemos a seguir:
```python
# Leitura de arquivos csv
with open('arquivos/matriz_exemplo.csv', 'r', encoding = 'utf8') as arquivo_exemplo:

    # Criando o objeto de leitura
    leitor = csv.reader(arquivo_exemplo)

    # Usando loop para ver o conteúdo:
    for x in leitor:
        print(x)
```
- Resultado:
```
['Coluna1', 'Coluna2', 'Coluna3']
[]
['12', '22', '83']
[]
['45', '34', '54']
[]
['19', '31', '8']
[]
['87', '56', '21']
[]
```

Os arquivos no formato de `.json`  (JavaScript Object Notation) também são amplamente utilizados no Data Science e na sua estrutura, basicamente é uma estrutura de dicionário pois utiliza pares de chave-valor para representar os valores.

```python
# Importando o módulo de JSON
import json

# Criando um dicionário
dict_botanica = {
    "gimnosperma": "pinheiro",
    "anacardiaceae": ["manga", "caju"],
    "leguminosae": ["feijão", "soja", "ervilha"],
    "poaceae": ["milho", "trigo", "arroz"],
    "solanaceae": ["batata", "tomate", "berinjela"],
    "rutaceae": ["laranja", "limão", "tangerina"]
}

for k,v in dict_botanica.items():
    print(k,v)

# Convertendo o dicionário para um objeto json
json.dumps(dict_botanica)

# Criando um arquivo para JSON
with open('botanica.json', 'w') as arquivo_botanica:
    arquivo_botanica.write(json.dumps(dict_botanica))
```
- O comando `json.dumps` irá converter um dicionário em objeto JSON onde pode ser inserido em um arquivo novo usando a função `open()`.

Podemos também abrir um arquivo e fazer uma leitura do arquivo usando o método `.read()`, porém só irá extrair apenas objeto JSON, e será necessário converter de volta para dicionário usando `json.loads()`.
```python
# Abrindo o arquivo em JSON
with open('botanica.json', 'r') as arquivo_botanica:
    texto = arquivo_botanica.read()
    dados = json.loads(texto)

print(dados)
```
