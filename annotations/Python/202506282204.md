## Extração de JSON disponível na Internet

É possível extrair os dados de um JSON que está na internet usando o módulo específico `urlopen` da biblioteca `urllib` como segue abaixo:
```python
# Extraindo os dados em JSON disponível na internet
from urllib.request import urlopen

response = urlopen('https://api.fda.gov/food/enforcement.json').read().decode('utf8')

dados = json.loads(response)

dados
```

Também é possível copiar e converter esses conteúdos em JSON para TXT com seguintes comandos:
```python
# Convertendo o arquivo em JSON para TXT
arquivo_fonte = 'botanica.json'
arquivo_destino = 'botanica.txt'

# Fazendo a conversão com o método 1
with open(arquivo_fonte, 'r') as fonte:
    texto = fonte.read()
    with open(arquivo_destino, 'w') as destino:
        destino.write(texto)

# Alternativamente, com o segundo método:
open(arquivo_destino, 'w').write(open(arquivo_fonte,'r').read())

# Abrindo o arquivo:
with open('botanica.txt', 'r') as botanica:
    texto = botanica.read()
    dados = json.loads(texto)
    print(texto, "\n")
    print(dados)
    
```
Resultado:
```
{"gimnosperma": "pinheiro", "anacardiaceae": ["manga", "caju"], "leguminosae": ["feij\u00e3o", "soja", "ervilha"], "poaceae": ["milho", "trigo", "arroz"], "solanaceae": ["batata", "tomate", "berinjela"], "rutaceae": ["laranja", "lim\u00e3o", "tangerina"]} 

{'gimnosperma': 'pinheiro', 'anacardiaceae': ['manga', 'caju'], 'leguminosae': ['feijão', 'soja', 'ervilha'], 'poaceae': ['milho', 'trigo', 'arroz'], 'solanaceae': ['batata', 'tomate', 'berinjela'], 'rutaceae': ['laranja', 'limão', 'tangerina']}
```
- Observe que `texto`, produzido a partir de apenas `.read()` sobre um arquivo de JSON é um conteúdo exato de JSON, enquanto `dados`, gerado a partir do `json.loads(texto)` é representação do JSON interpretado pelo Python. Isso gera diferenças na forma de como esses conteúdos são representados.
- No primeiro que está no formato bruto (ou conteúdo puro), com os caracteres de Unicode escapados como `\u00e3`, enquanto no segundo, há decodificação desses unicodes por parte do Python e armazenado no formato de dicionário do Python.
___

É importante destacar a diferença entre os pacotes e módulos. Os pacotes são um conjunto de módulos individuais organizados em uma estrutura de diretório. E os módulos são os scripts que contém as funções, classes e as variáveis que podem ser importados para o Python.
