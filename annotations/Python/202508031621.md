A expressão `raise` permite forçar a levantar ou disparar os erros ou exceções, geralmente quando se quer interromper o programa e avisar que algo deu errado. Ou seja, não permitir que o programa continue nas condições especificadas. Veja um exemplo abaixo:
```python
raise ValueError("Invalid value")
```
- No exemplo acima, o programa irá levantar o erro de valores. E isso pode ser usado dentro de uma função como no exemplo abaixo:
```python
def square_root_bisection(square_target, tolerance=1e-7, max_iterations=100):
    if square_target < 0:
        raise ValueError('Square root of negative number is not defined in real numbers')
```
- Ou seja, se `square_target` for menor que zero, o programa será interrompido e levantará uma mensagem de erro falando que as raízes quadradas nunca pode conter número negativo.

A palavra-chave `is` é semelhante ao == mas só que verifica se estão apontando para o MESMO OBJETO na memória, não apenas os valores.

Ou seja, se o valor de a for igual a 5, e o valor for igual a 5. Apesar de possuir os mesmos valores, mas não são os mesmos objetos. 
```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True → os valores são iguais
print(a is b)   # False → são objetos diferentes
```

Então, `is` verifica se é o mesmo objeto em questão.

O módulo `re.compile` pode transformar as expressões de regex em objeto reutilizável chamado de objeto de padrão ou "compiled pattern". Ou seja, invés de ter que escrever as expressões regulares todas as vezes, podemos só usar os objetos de padrão 
para aplicar os métodos como `.match()`, `.search()`, `.findall()` diretamente no objeto.
- Em termo de performance, o `re.compile()` é mais rápido pois tem a capacidade de reaproveitar em várias buscas e torna o código mais legível. 

Veja o exemplo abaixo:
```python
pattern = re.compile('l+')
quote = 'Not all those who wander are lost.'
print(pattern.search(quote))
```

```python

import re

# Compilando a regex
padrao = re.compile(r"\d{3}-\d{2}-\d{4}")
# Usando o padrão
resultado = padrao.search("Meu número é 123-45-6789.")

print(resultado.group())  # Saída: 123-45-6789
```


Os characters classes em regex são definidas pelos colchetes `[ ]` que permitem especificar um conjunto de caracteres que pode ocupar em única posição como no exemplo abaixo:
- `ma[dnt]` pode formar mad, man ou mat. 

Para pegar todas as letras alfabéticas em um character classes, tem que usar `[a-z]` que denota o alfabeto inteiro. Para incluir todos os números apenas, basta usar `[0-9]`.
- Agora para pegar todas as letras e números, podemos usar a expressão `[a-z0-9]`

O acento circunflexo `^` no início dos colchete denota a negação dos caracteres que vem logo seguida. Por exemplo, `[^0-9]` significa que só recebe apenas os caracteres que não sejam números, ou seja, aceitaria as letras e pontuações.

O ponto dentro de regex `.`  é caractere curinga e recebe UM caractere qualquer nesse espaço exceto o newline (\n). Por exemplo, a expressão `[a.b]` pode receber "aab", "acb", "aeb".
- Mas para pegar apenas o caractere de ponto, você precisa usar a contra barra para transformar em ponto "literal" como `\.`


Há outro tipo de string no Python que é bastante utilizada para escrever e tratar as expressões regulares: **raw string**. 

Normalmente as strings regulares com as aspas sem a expressão `r'` irá interpretar os caracteres de escape como `\n` e `\t`. Mas se usar o raw string, irá dizer ao Python para não interpretar os caracteres de escape ou contrabarras, mas tratar isso como literal.

```python
import re

# Sem raw string
padrao = "\\d+"   # precisa escrever \\d, senão Python vê \d como escape inválido
texto = "Tem 123 números"
print(re.findall(padrao, texto))  # ['123']

# Com raw string
padrao = r"\d+"   # agora só 1 barra, mais simples
print(re.findall(padrao, texto))  # ['123']

```

O character class `\d` é o mesmo para `[0-9]`. Por outro lado, `\D` é equivalente a `[^0-9]`. 

Os caracteres alfanuméricos podem ser escrito como `\w` (`[a-zA-Z0-9_]`) e a negação desses caracteres alfanuméricos (apenas caracteres não alfanuméricos com a exceção de `_`) pode ser escrito como `\W`  (`[^a-zA-Z0-9_]`).
- Vale destacar que o caractere `_` não é considerado como caracteres especiais, por essa razão acaba não sendo incluído em \W. Para isso, precisamos usar a outra alternativa que é `r'[!@#$%^&*(),.?":{}|<>]'`


Além disso, podemos também combinar vários classes de caracteres em único regex como `[a-d3-6]` que é a combinação de  `[a-d]` e `[3-6]`.

A função `all()` é uma forma de avaliar se os iteráveis contém os valores e chaves (se for um dicionário) considerados como todos verdadeiros. 
- Ou seja se todos os valores em iterável for verdadeiro, irá retornar como verdadeiro.
- Porém, se único valor for falso e os demais valores verdadeiros, a função `all()` irá retornar falso!
 
- O que seria considerado como falso seria:
	- número zero
	- None
	- False

- Mas em `all()`, os seguintes tipos de estrutura de dados são **VERDADEIROS**
	-  String vazia `''` (somente se for sozinha)
	- Lista vazia `[]`
	- Dicionário vazio
	- Tupla vazia `()`
	- Conjunto vazio `set()`

```python
print(all([]))        # True  → lista vazia
print(all(()))        # True  → tupla vazia
print(all(set()))     # True  → conjunto vazio
print(all(""))        # True  → string vazia
```
- Caso os iteráveis não tiverem alguns elementos dentro deles, serão retornados como verdadeiros porque não há nenhum elemento para ser avaliado, ou seja, não há elementos considerados como falsos.

Quaisquer outros valores diferentes daquilo que são da lista de falso acima contam como `True`. Mas presta a atenção nas particularidades distintas.

```python
print(all(["a", "b", "c"]))   # True → todos são strings não vazias (True)
print(all(["a", ""]))         # False → porque "" é string vazia, logo False
print(all(["", ""]))          # False → todos são falsos
```
- Ou seja, caso uma string vazia esteja com outros elementos dentro da função `all()`, será considerada como falso.


Outros exemplos:
```python
print(all([True, True, True]))       # True  → todos são True
print(all([True, False, True]))      # False → existe um False
print(all([1, 2, 3]))                # True  → todos números ≠ 0
print(all([1, 0, 3]))                # False → existe um 0
print(all([]))                       # True  → lista vazia (nenhum falso encontrado)
print(all(["a", "b", ""]))           # False → string vazia é falso
```

No caso dos dicionários, é importante considerar que apenas as chaves serão avaliadas, não seus respectivos valores!
```python
mydict = {0 : "Apple", 1 : "Orange"}
x = all(mydict)
print(x)
```
- Como a função `all()` avalia apenas as chaves do dicionário, o resultado desse exemplo seria `False`

import re

```python
def generate_password(length=16, nums=1, special_chars=1, uppercase=1, lowercase=1):

    # Define the possible characters for the password
    letters = string.ascii_letters
    digits = string.digits
    symbols = string.punctuation

    # Combine all characters
    all_characters = letters + digits + symbols

    while True:
        password = ''
        # Generate password
        for _ in range(length):
            password += secrets.choice(all_characters)
        
        constraints = [
            (nums, r'\d'),
            (special_chars, fr'[{symbols}]'),
            (uppercase, r'[A-Z]'),
            (lowercase, r'[a-z]')
        ]

        # Check constraints        
        if all(
            constraint <= len(re.findall(pattern, password))
            for constraint, pattern in constraints
        ):
            break
    
    return password

if __name__ == '__main__':
    new_password = generate_password()
    print('Generated password:', new_password
```
