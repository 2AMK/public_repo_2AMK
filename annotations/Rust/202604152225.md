Há diferença entre as funções e os macros. Os macros são denotados por "!" no finalzinho do nome. Por exemplo

```rust
fn main(){
	println!("Hello world!");
}
```

Para compliar um programa escrita simples, pode escrever no terminal o seguinte comando:
```bash
rustc nome_arquivo.rs
```

Esse comando fará com que complie e transforme em um executável e os outros arquivos compliados que pode ser rodado com o terminal:
```
.\nome_arquivo
```

O equivalente do pip e de gerenciador de pacote do Python é o Cargo e é muito útil para gerenciar os pacotes, as dependências e as bibliotecas que o projeto depende. Normalmente o cargo vem junto com o Rust.

Para criar um projeto usando o Cargo, segue o comando:
```bash
cargo new exemplo_cargo
```

Ao criar um cargo, o projeto já vem todas as estruturas básicas necessárias para ser um projeto como a pasta src, .gitignore e toml, o que é bem diferente do Python em que a criação de um env novo não necessariamente significa que o projeto já tenha criado automaticamente e precisa criar manualmente.

O toml é um espécie de requirement.txt e configuração básica do projeto.

O comando `cargo build` basicamente complia um projeto e gera um arquivo executável em um diretório bem específico (_target\debug\_)_ e não complia no próprio diretório atual.
- O build padrão é o debug e o Cargo por padrão coloca no diretório de debug

Para poder executar aquele build do Cargo, tem que escrever o seguinte comando:
```bash
./target/debug/exemplo_cargo
```

Para montar em um executável a partir de um projeto, tem que escrever o seguinte comando no diretório do projeto:
```bash
cargo run
```

Para verificar se o programa complia, use `cargo check`, e isso é útil para quando quer ver se o programa complia, não para gerar um executável.

Para importar uma biblioteca de Rust, assim como no Python, podemos escrever no início de um código com "use":
```rust
use std::io;
```
- o std significa uma biblioteca chamada de `std`
- o io significa um módulo chamado de `io`
- Seria equivalente em Python a chamar `from sys import stdin`
A biblioteca std::io permite utilizar as funções que podem receber o input de um usuário.

Para importar apenas uma função, tem que especificar a função depois do módulo:
```rust
use std::io::stdin;
```

Para declarar uma variável use `let` antes de uma variável, lembrando que no Rust a variável **sempre** por padrão é imutável, diferentemente do Python e JS
- Caso precise tornar mutável, tem que usar `let mut`

```rust
let mut cafe = 1; //Mutável
```

Quanto queremos declarar uma variável de um tipo específico, precisamos usar a sintaxe de `tipo_var::new();` para sinalizar que a variável que criamos está associada a uma nova instância de um tipo. 

O símbolo & dentro de um argumento de uma função indica que esse argumento é uma referência, e o comportamento dele permite que a mesma variável não seja copiada na memória várias vezes.
- Ou seja, referencia à memória onde fica a variável.
- Por padrão, as referências são imutáveis e caso queira referenciar a variável mutável, precisa declarar `&mut`

Em algumas funções como a `read_line` pode retornar também "Result", além do valor. O result é um dos tipos de ennumerations e pode retornar "Err" e "OK"
- Caso for "Err", o que significa erro ocorrido nas operaçoes e pode fazer com o programa crashar
- Caso seja OK, vai retornar com o valor de uma variável.

Podemos explicar por que ocorreu erro usando o método `.expect("explicacao do erro");`   
- Seria equivalente a "try except" em Python, mas no Rust precisa precisa ser mais explícito em relação aos erros e especificar os erros, diferentemente do Rust.
- Caso não utilize ".expect()"  o programa pode rodar normalmente, mas o compliador irá alertar sobre isso.

Assim como Python usa f-string para inserir os valores em um placeholder, o Rust usa as chaves `{placeholder}` para incluir os valores em um string.

E inclusive, assim como no Python, quando recebe o input de usuário com o stdin().read_line() (equivalente a input() em Python), o input recebido sempre será string e precisa converter para tipo correto.
- Para poder fazer a comparação entre as duas variáveis, devemos comparar com os mesmos tipos de variável

O método `parse` em string faz com que o string seja convertido em outro tipo. No exemplo acima, usamos para tentar converter os valores em String em I32.
- Mas claro que caso tiver caracteres não válidos sendo inseridos como input como "a32", o programa não vai aceitar.

A expressão de loop/laço no Rust é `loop{}`. Nesse laço, é necessário usar a expressão "break" em certa condição para poder sair do laço.

Para usar as bibliotecas que não estão nos pacotes padrões do Rust, devemos acrescentar as bibliotecas em `cargo.toml` e incluí-las na seção de dependências.


-------------
A outra variável imutável que tem no Rust é o `const` que são os valores atribuídos a um constante e não pode ser mudado. Seria parecido com o `const` em JS em que não podemos reatribuir o constante com os novos valores.
- Os constantes podem ser declarados em qualquer escopo, mesmo em global.
- De modo parecido em JS, a convenção de nomeação para os constantes é: `EXEMPLO_CONSTANTE`.
