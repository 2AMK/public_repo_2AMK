[[rust]]

As principais coleções do Rust são:
- Vetores: armazenar uma quantidade variável de valores de lado a lado;
- String: uma coleção de caracteres
- Hashmap: uma espécie de dicionário dinâmico, em que cada valor é associado a uma chave específica

Diferentemente dos tipos primitivos, as coleções armazenam os dados nos `heaps` cujo tamanho de dados é desconhecido no tempo de compliação e podem crescer ou reduzir de tamanho dinamicamente durante a execução.
- Cada tipo de coleção também tem suas capacidades e custos diferentes
